**WildeGate KeyBinds 1.1** — назначаемые клавиши для активных способностей рас сервера
WildeGate. По умолчанию **R** — способность №1, **G** — способность №2.

## Что нового в 1.1

* **Хендшейк работает и без плагина-моста.** Если сервер WildeGate не объявил канал
  `wildegate:keys`, мод проверяет дерево команд сервера и, увидев `/wgkey`, отправляет
  короткий хендшейк этой командой. Сервер сразу узнаёт, что мод установлен.
* **На чужих серверах мод по-прежнему молчит:** команды `/wgkey` там нет — значит,
  никаких сообщений и ошибок в чат не приходит.
* Хендшейк отправляется **один раз за вход**, а не пять.
* Мод готов к команде `/wildegatekeybinds` на сервере WildeGate: она показывает ссылку
  на скачивание игрокам без мода и выдаёт разовый стартовый набор игрокам с модом.

## Что внутри

* Две переназначаемые клавиши в категории «WildeGate: Способности».
* Отправка ID способности на сервер по каналу `wildegate:keys`:
  Fabric — только если сервер объявил канал; NeoForge — пакет и команда (лишнее срабатывание
  гасит анти-дубликат на сервере).
* Мини-хендшейк при входе: сервер понимает, что у игрока стоит мод, и отключает старые
  жесты — **F остаётся обычной сменой рук**, способности вызываются только биндами.
* Русская и английская локализации клавиш.
* Мод полностью клиентский, без телеметрии, обфускации и миксинов — три класса, можно прочитать.

## Что скачать

| Загрузчик | Файл | Дополнительно |
|---|---|---|
| Fabric | `wgkeybinds-fabric-1.1.jar` | нужен **Fabric API** |
| NeoForge 21.11.48+ | `wgkeybinds-neoforge-1.1.jar` | — |

Кладите JAR в `.minecraft/mods/`. На сервер мод ставить не нужно — серверная часть WildeGate
уже установлена.

## Проверка

* SHA-256 обеих сборок — в приложенном файле `SHA256SUMS.txt`.
* Исходники и инструкция «собери сам» (`gradlew.bat build`) — в репозитории.

**Требования:** Minecraft **1.21.11**, Java **21+**.
