# WildeGate KeyBinds

Клиентский мод для Minecraft **1.21.11**: назначаемые клавиши для двух активных способностей
рас сервера **WildeGate** (по умолчанию **R** — способность №1, **G** — способность №2).

Автор: **#bywanthh**. Исходники открыты специально, чтобы вы могли проверить, что ставите.

> Мод **только клиентский**. На сервер его ставить не нужно, а на любом другом сервере он
> вообще ничего не делает: серверную часть (Skript-систему рас и плагин-мост) мод не заменяет
> и никак не обходит.

## Что мод делает и чего не делает

**Делает:**

* добавляет в «Настройки → Управление → Назначение клавиш» категорию **WildeGate: Способности**
  с двумя переназначаемыми клавишами (по умолчанию R и G);
* по нажатию отправляет **текущему серверу, к которому вы подключены**, пакет `wildegate:keys`
  с одним числом: `1` — способность №1, `2` — способность №2;
* при входе отправляет такой же пакет с числом `0` (мини-хендшейк «мод установлен»), чтобы
  сервер сразу отключил старую механику жестов и F остался обычной сменой рук.

**Не делает:**

* **никакой телеметрии и аналитики**: мод не ходит в интернет, не открывает своих соединений
  и ничего не отправляет третьим лицам;
* не читает чат, инвентарь, координаты, ваши файлы и прочие данные;
* не содержит обфусцированного кода и миксинов в ванильные классы;
* не меняет геймплей сам по себе — только отправляет одно число серверу.

**Весь код — три класса**, плюс иконка и две локализации:

| Файл | Что там |
|---|---|
| `fabric/src/client/java/ru/wildegate/keys/WildeGateKeysClient.java` | кейбинды, отправка пакета, хендшейк (Fabric) |
| `neoforge/src/main/java/ru/wildegate/keys/WildeGateKeysClient.java` | то же для NeoForge |
| `.../AbilityPayload.java` | описание пакета: одно число (VarInt) |
| `.../WildeGateKeys.java` | три константы: id мода, канал, имя внутренней команды |

Прочитать всё можно за пару минут — в этом и смысл.

## Скачать

Готовые сборки лежат в папке [`release`](release) этого репозитория:

| Файл | Куда ставить | Что нужно |
|---|---|---|
| `wgkeybinds-fabric-1.0.jar` | `.minecraft/mods/` | Fabric Loader + **Fabric API** |
| `wgkeybinds-neoforge-1.0.jar` | `.minecraft/mods/` | **NeoForge 21.11.48+** |

Хеши SHA-256 — в [`release/SHA256SUMS.txt`](release/SHA256SUMS.txt). Проверить скачанное:

```powershell
Get-FileHash .\wgkeybinds-fabric-1.0.jar -Algorithm SHA256
```

```bash
sha256sum wgkeybinds-fabric-1.0.jar
```

## Как убедиться, что JAR собран именно из этого кода

1. Скачайте исходники (кнопка **Code → Download ZIP**) или склонируйте репозиторий.
2. Соберите сами:
   ```
   cd fabric      # или cd neoforge
   gradlew.bat build        # Windows
   ./gradlew build          # Linux/macOS
   ```
   Требования: **JDK 25** для запуска Gradle (wrapper 9.8.1 уже в комплекте), сами моды
   компилируются под Java 21 и требуют Minecraft 1.21.11 (зависимости Gradle скачает сам).
3. Получится `build/libs/wgkeybinds-*.jar` с тем же набором классов, что и в релизе.
   Чтобы сверить побайтово — распакуйте оба JAR (это обычный ZIP) и сравните
   `ru/wildegate/keys/*.class`, `fabric.mod.json` / `META-INF/neoforge.mods.toml`.

Ничего, кроме этих трёх классов, метаданных, иконки и локализаций, в JAR не лежит —
это видно и по размеру файла (~100 и ~200 КБ).

## Установка

1. Поставить загрузчик: Fabric Loader (для Fabric-версии) или NeoForge 21.11.48+
   (для NeoForge-версии), Minecraft **1.21.11**.
2. Положить JAR в папку `.minecraft/mods/` (для Fabric — вместе с Fabric API).
3. Запустить игру. Клавиши при необходимости переназначить в
   «Настройки → Управление → Назначение клавиш → WildeGate: Способности».

## Требования

* Minecraft **1.21.11**
* Fabric: Loader 0.19.5+ и Fabric API · NeoForge: 21.11.48+
* Java 21+
